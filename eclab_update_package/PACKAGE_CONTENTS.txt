SOURCE FILES (source_files/biologic/):

  eclab_olecom_interface.h (1.5 KB)
    - COM interface definition (IEClabExe)
    - From Bio-Logic EC-Lab OLE COM User Manual
    - Windows COM structures and typedefs
    - Interface vtable definition
    - NO IMPLEMENTATION - header only

  eclab_olecom.h (18 KB)
    - EC-Lab OLE COM wrapper header
    - Connection management functions
    - Channel control functions
    - Measurement monitoring functions
    - .mpr file reading functions
    - Error codes and constants
    - Data structures

  eclab_olecom.c (45 KB)
    - EC-Lab OLE COM wrapper implementation
    - Windows COM automation code
    - String/BSTR conversion utilities
    - VARIANT/SAFEARRAY parsing
    - Connection lifecycle management
    - Measurement execution and monitoring
    - .mpr file data extraction
    - Comprehensive error handling and logging

  biologic_eclab.h (8 KB)
    - High-level EC-Lab mode interface
    - Technique execution functions
    - .mpr to BIO_TechniqueData conversion
    - Configuration structures
    - Function prototypes

  biologic_eclab.c (32 KB)
    - EC-Lab technique implementations:
      * OCV (Open Circuit Voltage)
      * PEIS (Potentiostatic EIS)
      * GEIS (Galvanostatic EIS)
      * GCPL (Galvanostatic Cycling)
    - .mps file loading
    - Measurement monitoring with progress callbacks
    - .mpr file reading and parsing
    - Data conversion to BIO_TechniqueData format
    - Timeout handling
    - Error recovery

  biologic_abstract.h (12 KB)
    - Mode abstraction layer header
    - Unified interface for both DLL and EC-Lab modes
    - Mode selection and switching functions
    - Mode-agnostic technique functions
    - Configuration management
    - Function prototypes for all techniques

  biologic_abstract.c (38 KB)
    - Abstraction layer implementation
    - Automatic mode dispatching
    - Runtime mode switching support
    - Queue manager integration
    - Technique wrappers:
      * BIO_Abstract_RunOCV()
      * BIO_Abstract_RunPEIS()
      * BIO_Abstract_RunGEIS()
      * BIO_Abstract_RunGCPL()
    - Parameter forwarding to appropriate mode
    - Error handling and logging

================================================================================
FILE DEPENDENCIES
================================================================================

Dependency Tree:

  Your Application
    └─> biologic_abstract.h/c  (NEW - mode abstraction)
         ├─> biologic_dll.h/c  (EXISTING - Direct DLL mode)
         │    └─> ECLib64.dll
         │
         └─> biologic_eclab.h/c  (NEW - EC-Lab mode)
              └─> eclab_olecom.h/c  (NEW - COM wrapper)
                   ├─> eclab_olecom_interface.h  (NEW - COM interface)
                   └─> OLE32.lib  (Windows COM library)

Integration Requirements:
  1. All NEW files must be added to project
  2. OLE32.lib must be linked
  3. common.h must include configuration constants
  4. Initialization must call BIO_Abstract_SetQueueManagers()
