PROBLEM SUMMARY
================================================================================

The "zero-current charging" approach (commit cc12e67) correctly avoided writing
to REG 501 (SET_CURRENT) but FAILED in ops-log-2026-01-13-04.txt because:

TEST RESULT (ops-log-04):
  Configuration BEFORE output enable (lines 425-455):
    - REG 498 (SINK_MODE_POWER): 30.58 W ❌ (NON-ZERO!)
    - REG 499 (SINK_MODE_CURRENT): 5.10 A ❌ (NON-ZERO!)
    - REG 500 (SET_VOLTAGE): 4.28 V (target)
    - REG 501 (SET_CURRENT): 0.00 A ✓ (correctly zeroed)
    - REG 502 (SET_POWER_SOURCE): 0.00 W ✓
    - Device state: CV (SOURCE mode) ✓

  AFTER output enable (line 477):
    - PSB Mode: CP (SOURCE mode) ❌
    - Current: 0.000 A ❌
    - Charging failed immediately

ROOT CAUSE IDENTIFIED:
  The "minimalist approach" of NOT WRITING to sink registers (REG 498/499)
  was based on the assumption that the PSB would use safe factory defaults.

  WRONG ASSUMPTION: Sink registers RETAIN VALUES from previous operations.

  In ops-log-04:
    - REG 498 = 30.58W (retained from previous session or changed by firmware)
    - REG 499 = 5.10A (retained from previous session or changed by firmware)

  PSB mode selection algorithm sees THREE non-zero setpoint registers:
    - REG 498 (sink power): 30.58W
    - REG 499 (sink current): 5.10A
    - REG 500 (voltage): 4.28V

  Multiple non-zero setpoints → AMBIGUOUS MODE → PSB defaults to CP mode

WHY OPS-LOG-02 WORKED:
  In the successful discharge test (ops-log-02), sink registers had different
  retained values:
    - REG 498 = 101.98W (higher value)
    - REG 499 = 10.20A (higher value)

  These higher values allowed CV SINK mode to work for discharge because the
  battery voltage (2.74V) was higher than target (2.70V), making SINK the
  correct operation mode. The 30.58W/5.10A values in ops-log-04 may be hitting
  some firmware threshold that triggers CP mode instead.

CRITICAL INSIGHT:
  We cannot assume sink registers are at safe defaults. We must EXPLICITLY
  WRITE ZERO to ensure ONLY the voltage register (REG 500) has a non-zero value.

================================================================================
SOLUTION: EXPLICIT SINK REGISTER ZEROING
================================================================================

Before configuring charging parameters, EXPLICITLY ZERO all setpoint registers
except voltage:

CONFIGURATION SEQUENCE (revised):
  Step 0: ZERO SINK REGISTERS (NEW!)
    - Write REG 498 (SINK_MODE_POWER) = 0.0 W
    - Write REG 499 (SINK_MODE_CURRENT) = 0.0 A

  Step 1: Set current LIMIT (not setpoint)
    - Write REG 9002 (CURRENT_MAX) = 3.3 A
    - Keep REG 501 (SET_CURRENT) = 0.0 A

  Step 2: Set power LIMIT
    - Write REG 9004 (POWER_MAX) = 30 W
    - Keep REG 502 (SET_POWER_SOURCE) = 0.0 W

  Step 3: Set voltage SETPOINT (last!)
    - Write REG 500 (SET_VOLTAGE) = 4.2 V

  Step 4: Verify register state
    - Log all registers to confirm only REG 500 is non-zero

RESULT:
  Only ONE setpoint register (REG 500) has a non-zero value → PSB must select
  CV mode. All other registers are explicitly 0.0, eliminating ambiguity.

================================================================================
LESSONS LEARNED
================================================================================

1. NEVER ASSUME DEFAULT VALUES
   - PSB registers retain values across operations
   - "Not touching" a register ≠ "setting it to zero"
   - Always explicitly write desired values

2. PSB MODE SELECTION IS STRICT
   - Any non-zero value in setpoint registers (498-502) is considered
   - Multiple non-zero setpoints → ambiguous → defaults to CP mode
   - Must ensure ONLY ONE setpoint register is non-zero

3. DEBUGGING REQUIRES COMPLETE VISIBILITY
   - Register dump logging was essential to identify this issue
   - Without seeing REG 498/499 values, we would have missed the root cause
   - Always log ALL relevant registers, not just the ones you write

4. INCREMENTAL FIXES CAN REVEAL NEW ISSUES
   - First fix (cc12e67): Avoided REG 501 writes → still failed
   - Second fix (this): Must also zero REG 498/499 → TBD
   - Complex systems require thorough understanding of ALL state
