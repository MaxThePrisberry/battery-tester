PROBLEM SUMMARY
================================================================================

Test results from minimalist approach (ops-log-2026-01-13-02.txt and -03.txt)
revealed an asymmetry in PSB behavior:

  ✅ DISCHARGE SUCCESS (log -02):
     - Configuration: Only write REG 500 (voltage), REG 501 = 0.0A
     - Result: CV SINK mode, current flowed (1.637A → decreasing)
     - Battery successfully discharged

  ❌ CHARGING FAILURE (log -03):
     - Configuration: Write REG 501 = 3.3A, then REG 500 = 4.2V
     - Result: PSB switched to CP mode after output enable
     - Current: 0.000A (no charging occurred)

ROOT CAUSE IDENTIFIED:
  The PSB mode selection algorithm interprets REG 501 (SET_CURRENT) as a
  SETPOINT register, not a limit register. Writing a non-zero value to REG 501,
  even with the intention of setting a "current limit," causes the PSB to
  consider both current and voltage as active setpoints, leading to Constant
  Power (CP) mode selection.

================================================================================
SOLUTION: ZERO-CURRENT CHARGING APPROACH
================================================================================

Mirror the successful discharge pattern for charging operations:

  DISCHARGE (working):
    - Write ONLY REG 500 (voltage setpoint)
    - REG 501 (source current) = 0.0A
    - REG 498/499 (sink defaults) = 10.20A / 101.98W
    - Result: CV SINK mode selected

  CHARGING (new approach):
    - Write ONLY REG 500 (voltage setpoint)
    - Keep REG 501 (source current) = 0.0A
    - Use REG 9002 (CURRENT_MAX) for current limiting
    - Expected: CV SOURCE mode selected

KEY INSIGHT:
  The PSB firmware makes mode selection decisions based on which SETPOINT
  registers (498-502) contain non-zero values. To force CV mode, we must
  ensure ONLY the voltage register (REG 500) has a non-zero value, and
  use LIMIT registers (9000-9009) for all constraints.

REGISTER MAPPING REFERENCE
================================================================================

SETPOINT REGISTERS (498-502): Determine active control mode
  REG 498: SINK_MODE_POWER       [Keep at factory default: 101.98W]
  REG 499: SINK_MODE_CURRENT     [Keep at factory default: 10.20A]
  REG 500: SET_VOLTAGE           [Write target voltage HERE]
  REG 501: SET_CURRENT           [Keep at 0.0A for CV mode]
  REG 502: SET_POWER_SOURCE      [Keep at 0.0A for CV mode]

LIMIT REGISTERS (9000-9009): Constrain operation
  REG 9000: VOLTAGE_MAX          [61.2V]
  REG 9001: VOLTAGE_MIN          [0.0V]
  REG 9002: CURRENT_MAX (SOURCE) [Write current limit HERE: 3.3A]
  REG 9003: CURRENT_MIN (SOURCE) [0.0A]
  REG 9004: POWER_MAX (SOURCE)   [Write power limit HERE: 30W]
  REG 9005: SINK_POWER_MAX       [1224W]
  REG 9008: SINK_CURRENT_MAX     [61.2A]
  REG 9009: SINK_CURRENT_MIN     [0.0A]

DEVICE STATE REGISTER (505): Read-only status
  Bits 0-4:   Control location (3 = USB/Modbus)
  Bit 7:      Output enabled (1 = on, 0 = off)
  Bits 9-10:  Regulation mode (0=CV, 1=CR, 2=CC, 3=CP)
  Bit 11:     Remote mode (1 = remote, 0 = local)
  Bit 12:     Sink/Source (1 = sink, 0 = source)
  Bit 15:     Alarms active (1 = alarms, 0 = no alarms)

================================================================================
PSB MODE SELECTION ALGORITHM (INFERRED)
================================================================================

Based on 30+ debugging iterations and test results, the PSB firmware appears
to use this decision tree for mode selection:

1. Check which setpoint registers (498-502) have non-zero values
2. If ONLY REG 500 (voltage) is non-zero:
   → Select CV (Constant Voltage) mode
   → Choose SINK or SOURCE based on battery voltage vs setpoint
3. If REG 501 (current) is non-zero:
   → Consider CC (Constant Current) mode
4. If REG 502 (power) is non-zero:
   → Consider CP (Constant Power) mode
5. If multiple setpoint registers are non-zero:
   → Mode selection becomes ambiguous
   → May default to CP mode
   → May use "last written wins" heuristic

CRITICAL RULE:
  To reliably select CV mode, ensure ONLY REG 500 has a non-zero value.
  Use limit registers (9000-9009) for all protection and constraints.
